# Terminology

These definitions describe Draft 0.1.0 and are informative rather than a client protocol.

- **Router:** The root `AGENTS.md` file that directs an agent to additional context.
- **Route:** A condition and project-relative path written in the router.
- **Routed context:** A file an agent reads because a route applies to its current task.
- **Progressive disclosure:** Loading detailed context only after a relevant route or skill is selected.
- **Rule:** A project instruction whose applicability is stated by the router.
- **Persona:** An optional specialist perspective used for a particular activity.
- **Skill:** A task-specific instruction package conforming to the Agent Skills specification.
